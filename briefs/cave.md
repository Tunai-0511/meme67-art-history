# cave — 約 40,000 BCE · 洞穴壁畫（影片 4.0–10.0 s，6 s = 3 小節）
**要像**：法國蕭維／拉斯科洞窟的壁畫——火把光下的石灰岩壁，炭黑輪廓的野牛、馬、猛瑪象，赭紅/黃赭色塊，噴塗的「手掌輪廓」。
**畫面**
- 岩壁：暖灰褐（#6b5444 → #8b6f58）凹凸石面，用 noise 做出「受光的浮雕」（法線式打光：火把光源在畫面某處、**會閃爍並緩緩飄移**，光圈外迅速變暗；角落全黑）。鐘乳石/裂縫、方解石白斑、岩壁天然隆起被畫家順勢當成野牛的肩膀。bake 靜態岩壁，光影用 2D 層 multiply/screen 疊。
- 壁畫主體：一隻大野牛（拉斯科/阿爾塔米拉式：駝峰、小蹄、多重輪廓線、赭紅填色用炭筆排線 `charcoal` + 紅赭 hatch 或 `bristle`），旁邊一匹馬、一隻猛瑪象/鹿較小、較淡（遠近重疊畫）。多重輪廓＋「重複描線」是洞窟畫的特徵。
- **做 67 的角色**：(a) 兩三個蕭維式的火柴人獵人（細長身軀、梯形/圓點頭、細腿），雙臂彎曲前伸，交替上下；(b) **野牛的兩隻前蹄交替上下**（主笑點）；(c) 牆上要有**噴塗手掌印**（用 2D 層：撒大量細點，再以手掌形狀 `destination-out` 挖出，赭紅/黑/白各一組；其中一排手掌印做成「左手掌/右手掌」交替閃亮，跟著 six/seven 亮起）。
- six/seven 的寫法：洞穴的計數**刻痕**——牆上一組 6 道、一組 7 道的豎線（炭黑/赭紅），隨 `V.G.say` 輪流發亮（亮=更不透明＋微微放大）。
- 質感：炭筆粗糙邊緣、顏料滲進岩壁凹凸（可用 2D 層 multiply 疊同一張岩壁紋理讓顏料「陷進去」）、火光暖橘、空氣中飄浮微塵（少量，慢）。
- 年份區（左上）與標籤卡（右下）背景請保持較暗、較少細節。年份字色為暖橘黃（#f0b560）。
**色票**：岩壁 #5e4a3b / #8a6e56、炭黑 #17110d、赭紅 #a8432a、黃赭 #d79b3a、白堊 #efe6d2、火光 #ffb55a。
**動態**：火光閃爍（慢）、獵人與野牛手/蹄交替、身體隨 pulse 下沉、刻痕輪流亮、一點塵埃。
