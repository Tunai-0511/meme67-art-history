# ukiyo — 1831 · 浮世繪《神奈川沖六七裏》（38.0–42.0 s，4 s）
**要像**：葛飾北齋《神奈川沖浪裏》——普魯士藍巨浪的「爪狀」浪尖、白色泡沫指、遠方小小的富士山、三艘押送船（oshiokuri-bune）上的船夫；木版畫的平版色塊＋墨線、米色和紙、天空上緣的漸層暈染（bokashi）。
**畫面**
- 底：米色和紙（#efe2bf，纖維與微汙漬），天空：上方淡灰褐/粉橘的橫向漸層（上深下淺）＋幾條平行的雲帶。bake。
- 巨浪：左側升起、向右前傾的大浪；用 V.fill 平塗深藍 #1c3f7a / #0f2a5a（兩三個色階像是多版套印），**浪的下緣與捲曲處以細墨藍線勾勒（木版刻線感，筆寬細且帶頓挫）**；浪尖分裂成多隻「爪子」，**爪子與白色泡沫點（成百小圓點）輕輕顫動**；浪背有漣漪的平行弧線紋理。
- 遠景：**富士山**（小，在浪下方缺口中，山頂雪白、山腰藍灰），海面條紋。
- 三艘船（長條船，淡黃褐 #d9b46a 配深色船舷）在浪谷中起伏：**每艘船上坐著 6–8 位船夫，兩手都在做 67**（只需簡化：深藍頭巾、淺色圍裙、黑髮，兩臂前伸交替上下；彼此同相，小比例 ~60–90 px）。
- 圖題框：右上一塊**長方形題簽（cartouche）**內有直排日文「神奈川沖六七裏」＋小字「冨嶽三十六景」，旁邊一方紅色**落款方印**（北齋風格的印）；字用 Hiragino Mincho，墨色。年份（左上）字色墨藍配和紙色描邊；標籤卡（右下）壓在海面。
- 質感：木紋（淡淡的橫向木紋 2D 紋理 multiply）、套印微微錯位（讓某層色塊位移 1–2 px）、顏色略舊。
**色票**：普魯士藍 #1c3f7a/#0f2a5a/#3c6fb0、和紙 #efe2bf、泡沫白 #f7f2e4、船 #d9b46a、朱 #c23a2b、墨 #1a1a24。
**動態**：浪的呼吸（整體緩慢上下 + 爪子顫動，與拍子同步）、船隨浪頂浮、船夫 67、泡沫點閃動。
