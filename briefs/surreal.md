# surreal — 1931 · 超現實《六點七分的永恆》（46.0–50.0 s，4 s）
**要像**：達利《記憶的永恆》——夢境荒原，極度寫實光滑的細節卻荒謬：融化的軟鐘、枯樹枝、桌角、遠處加泰隆尼亞海岸的金色懸崖與平靜的海、橙褐色平原、天空由天藍漸變到金橙。
**畫面**
- 天空與地景（2D 層漸層，光滑如噴槍）：天空從上方暗青藍 #1e4a6e 到地平線暖金 #f0b45a；海面一條細長的淡青 #5a8f9a 帶；右側**金色/赭色懸崖**（Cap de Creus，受側光有明暗面）；前景荒原是暖褐橙 #8a5a30 帶長長的陰影。
- **三只融化的軟鐘**（懷錶，金色錶殼、象牙錶面，錶盤上有羅馬或阿拉伯數字，錶殼融化垂掛）：一只掛在枯樹枝上、一只垂在桌角/平台邊、一只攤在地上（螞蟻群聚在一只橘色硬錶上）。**所有鐘面的指針都指向 6:07**（時針在 6、分針在 1.4 的位置，細而精準）——這就是笑點與標題。
- **67 的主角**：畫面中央兩隻**超大的、寫實的手**（從沙地裡伸出，像天平），**掌心向上，各託著一只軟鐘，交替升降**（這樣「蹺蹺板」非常直觀）；手需要有皮膚漸層、指節、陰影（2D 漸層 + brush 細節）。左側那只「軟自畫像」（睡著的側臉怪物，長睫毛）也隨拍呼吸起伏（可簡化為輪廓＋睫毛）。
- 質感：畫面要有油畫的「光滑精修」感（柔漸層，無明顯筆觸）＋極細的高光；可用 `V.gradient` + 2D 徑向漸層 + `blur` 做柔陰影，再用 brush 細筆（`2H`/`HB` 色鉛筆級）補微細節（皺褶、螞蟻、枯樹紋）。長長的詭異陰影方向一致。
- 年份（左上，Didot 米金）區在暗青天空，OK；標籤卡（右下）落在前景荒原。
**色票**：天青 #1e4a6e、金橙 #f0b45a、荒原 #8a5a30/#c88a4a、懸崖 #c98c3a/#6a3d1f、海 #5a8f9a、錶金 #e0b040、錶面 #f1e6c4。
**動態**：兩隻手＋軟鐘 67、鐘面指針其實不動（永遠 6:07）但鐘的垂掛隨手的升降形變、螞蟻小爬、懸崖光緩慢移動。
