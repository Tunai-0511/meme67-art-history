# synth — 1985 · 合成器浪潮《夜駛六七》（54.0–58.0 s，4 s）
**要像**：1980 年代 synthwave / outrun 海報與 VHS 錄影帶——紫粉橙漸層天空、被橫線切開的巨大夕陽、透視網格地面向地平線飛馳、剪影棕櫚樹、遠山線框、霓虹、鉻金屬字。
**畫面**
- 天空：#12062e（上）→ #3b0a6b → #c2185b → #ff6a3d（地平線）漸層（V.gradient）＋星點；**巨大夕陽**（圓，黃→粉漸層，下半被**越往下越粗的水平黑縫**切開，縫會**隨時間向上爬**，經典 outrun 動畫）。
- 地面：深紫黑 #0a0220，**霓虹青 #27e9ff / 洋紅 #ff3ec9 透視網格**（橫線向觀眾加速移動、垂直線向地平線匯聚），格線有輝光（同一線畫 3 次：寬低 alpha、中、細亮）；遠處兩側**線框山脈**（洋紅輪廓，內部同色暗填）。兩側**棕櫚樹剪影**（黑，頂部被夕陽輪廓光勾邊）。
- **主角**：畫面中央偏左的人物**背對/側對夕陽的黑色剪影**（皮夾克、墨鏡、尖挺髮型，**霓虹粉＋青雙色邊緣光**），雙手前伸做 67（動作做大、有 funky 感，膝蓋隨拍彈）。旁邊一個同樣風格的角色或一輛線框跑車（Testarossa 風）也可，但要有 2 位以上做 67。
- 鉻金屬大字「67」（漸層：白→藍→暗→橘的鉻面分層，加霓虹外框 + 倒影）置於夕陽上方或側邊，斜體；隨 `V.G.say` 在「6」「7」之間切換霓虹亮度。
- **VHS 後製**（最後套整幀）：用 2D 層做橫向掃描線（multiply）、色散（RGB 位移：把畫面以不同偏移 screen/add 疊三次不容易，替代：只對文字與邊緣光做偏移）、**一條緩緩下移的追蹤雜訊帶**（水平位移撕裂）、輕微暗角、CRT 光暈（`ctx.filter='blur'` 的高光層 screen）。
- 年份（左上，Futura 斜體洋紅配青色光暈）在天空上很顯眼；標籤卡（右下）在網格地面上 OK。
**色票**：#12062e #3b0a6b #c2185b #ff6a3d #ffd23f / 霓虹 #27e9ff #ff3ec9 / 黑 #0a0220。
**動態**：網格前進、夕陽縫上爬、主角彈跳 67、字亮度輪流、VHS 雜訊帶下移。
