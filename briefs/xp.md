# xp — 2006 · 早期網路《轉寄》（62.0–66.0 s，4 s）
**要像**：2006 年台灣的 Windows XP 桌面：Bliss 綠丘藍天、Luna 藍色標題列的視窗、工作列與「開始」綠按鈕、MSN Messenger 對話視窗、轉寄連鎖信、Flash 時代的氛圍。
**畫面**
- 桌布：Bliss（綠丘、藍天、白雲：用 2D 漸層＋柔邊多邊形近似，要認得出來），左側一排桌面圖示（我的電腦、資源回收筒、「67.exe」、「轉寄.txt」…，圖示用簡單像素/向量圖案＋白字下有藍底選取框）。
- 底部工作列（Luna 藍漸層）、綠色「開始」按鈕、右下角系統匣時鐘寫 **6:07 PM**（笑點）。
- **MSN Messenger 視窗**（中央偏右）：藍色 Luna 標題列＋最小化/最大化/關閉按鈕、聯絡人頭像（綠色小人）、對話氣泡：顯示對話逐行出現（Trebuchet/Tahoma 風格 12 級放大成 ~32 px 以利閱讀）：「ㄎㄎ」「6」「7」「轉寄給 67 個人，願望就會實現 ^_^」「不轉會倒楣 67 年」；**黃色圓臉表情符號（MSN 風格，立體圓臉）有雙手（跟著手勢交替上下）**——**表情符號和視窗右側的「顯示圖片」頭像（一個像素風/向量人物）做 67**；在每個「seven」拍點執行 **「震動視窗」（nudge）**：整個視窗左右抖動 ~10 px 0.2 秒。
- 另一個疊在後面的視窗：**轉寄信件**（Outlook Express 風）：標題「Fw: Fw: Fw: 這個手勢超神！！」，內文用紅色/粗體大字「看到請轉寄給 67 個人」，附件圖示。
- 一個 Windows 錯誤對話框彈出：「六七.exe 發生問題，必須關閉」（紅叉圖示、確定按鈕）在 u≈2.5 s 出現（動畫彈入 + 「叮」）。
- 滑鼠游標（白箭頭黑邊）慢慢移動並在按鈕上點擊。
- 年份（左上，白字藍描邊 Trebuchet）配綠色 pill 蓋在天空上很搭；標籤卡（右下）放在工作列上方——請別在那裡放視窗。
**色票**：XP 藍 #0a58ca→#3a8cf0（標題列漸層）、#245edb、綠 #3b9a30 / #78c850（開始鈕）、Bliss 綠 #5aa02c、天 #4a90e2、視窗灰 #ece9d8。
**動態**：對話逐行出現、表情符號與頭像 67、震動視窗、游標移動、錯誤對話框彈出、時鐘秒閃爍。
