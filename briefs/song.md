# song — 約 1000 CE · 北宋水墨山水（26.0–30.0 s，4 s）
**要像**：范寬《谿山行旅圖》——一座頂天立地的巨大主峰佔據畫面中央（正面全景式構圖），密密的「雨點皴」，山腰雲霧，右側細長瀑布，山腳林石與小路上的行旅騾隊；絹本、淡褐黃的古絹色。
**畫面**
- 底：古絹（#d8c79c → #c9b684，**絹的經緯細紋**用 2D 層畫極細格紋＋做舊斑），邊緣燻暗。bake。
- 山：用 p5.brush 的 `bristle`/`charcoal`（墨色 #1a1714，各種濃淡 alpha）逐層畫：主峰輪廓（粗大濃墨）→ **雨點皴**（成千上萬的短豎點，從山頂密到山腰；用 V.rng 固定位置，**bake**）→ 淡墨水墨暈染（`V.fill(..., {flat:false})` 低 alpha 或 2D 層 blur）→ 山腳松樹叢（濃墨點葉）與巨石。雲霧：幾條橫向留白帶（絹色半透明漸層）**緩慢飄移**。
- 瀑布：右側一道細長的垂直留白線，帶幾筆淡墨，有水霧。
- 前景小路上：**兩位行旅者（一位挑夫、一位文人，小比例，約 120–180 px 高）和一頭騾**，他們**雙手掌心向上交替上下做 67**（水墨寫意畫法：衣袍用濃淡墨塊，臉不畫五官只畫笠帽，手臂以粗細有致的幾筆表現；做手勢時笠帽微晃）。山的巨大與人的渺小是笑點。
- 題款：右下小字用楷體/行楷寫「谿山行旅六七圖」（直排），旁蓋 **朱砂印章**（方形，白文「六七」用篆意：四角略破、紅 #b0281c，並帶些微印泥不均）；左上方可有一方小章「67」。 
- 年份（左上）字色墨黑（#26201a，楷體），已無描邊，要放在山以外的淡絹區；標籤卡（右下）放在有題款的角落，**題款往左上移避開**。
**色票**：絹 #d4c394、墨 #1a1714 ～ #8a847a（淡墨）、朱 #b0281c、微量赭石 #a67c52。
**動態**：雲霧飄移、瀑布水霧微動、樹梢微動、行旅者與騾子做 67（騾子的兩前蹄也交替更佳）、印章在 u≈1.0 s「蓋」下去（落下縮放 + 一點壓痕）。
